# Bitcoin Sentiment Analysis from Twitter Data

This project analyzes public sentiment on Bitcoin based on tweets published on Twitter, using Natural Language Processing techniques and tools for large-scale data analysis.

## Objective

- Analyze sentiment expressed in tweets (positive, negative, neutral)
- Study user interaction levels (likes and replies)
- Investigate potential relationships between sentiment and Bitcoin price variations

## Data

- Dataset of tweets related to Bitcoin
- Dataset enriched with sentiment classification
- Historical dataset of Bitcoin price

## Tools

- Python (Google Colab and Kaggle)
- PySpark
- Transformers (NLP)
- Pandas, NumPy, Matplotlib

## Results

- Identification of sentiment distribution
- Analysis of temporal evolution of tweets
- Comparison of interactions generated by different sentiment classes
- Analysis of correlation between sentiment and Bitcoin price
